# 1. Описание проекта XKCD Comic Publisher

Скрипт для автоматического скачивания случайных комиксов с сайта xkcd и их публикации в Telegram-канал.

## 2. Требования к окружению

- ОС: Linux, macOS, Windows
- Python: версия 3.8 или выше
- Доступ к интернету для запросов к API
- Telegram бот и канал

## 3. Как установить

### Установите зависимости:
```bash
pip install -r requirements.txt
```

### Настройте переменные окружения:
Создайте файл .env в корне проекта. В файле необходимо объявить две переменные конфигурации. Значения указываются без кавычек и пробелов.

TELEGRAM_BOT_TOKEN — уникальный токен вашего Telegram-бота, полученный от отца ботов @BotFather.
TELEGRAM_CHANNEL_ID — уникальный идентификатор или имя вашего целевого Telegram-канала (например, -1001234567890).

Шаблон для копирования в файл .env:
```bash
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHANNEL_ID=
```

## 4. Использование скрипта
```bash
python main.py
```

## 5. Пример запуска и проверка результата
```bash
$ python main.py
```
В вашем Telegram-канале появится случайный комикс xkcd с оригинальным alt-текстом в качестве подписи.

### Примечание:
Скрипт автоматически выбирает случайный комикс, скачивает его во временный файл, публикует в указанный канал и полностью удаляет локальный файл после завершения работы
